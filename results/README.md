# Results

Store concise, reproducible outputs here, such as a metrics table or plots generated by the notebooks.

Before adding results, record:
- dataset and split protocol;
- model and training configuration;
- baseline/federated/private evaluation metrics;
- federated client count and communication rounds;
- differential-privacy parameters and computed epsilon/delta;
- random seed and relevant library versions.

Do not add raw data, private recordings, or large model checkpoints.
